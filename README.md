## Featured Projects

### [Enlight](https://github.com/arkaazattar/enlight-htn2026)
**Python · OpenCV · FastAPI · MongoDB · Next.js · Gemini**

AI-powered visual memory assistant built at **Hack the North 2026**. Combines real-time face recognition, persistent identity tracking, live transcription, contextual memory extraction, and location-aware features.

### [ClashRecruit](https://github.com/arkaazattar/ClashRecruit)
**Python · Flask · React · MongoDB · Celery · AWS EC2**

Full-stack Clash of Clans recruitment platform deployed on AWS EC2, with authenticated listing management, background processing, API caching, and a live directory of 350+ recruitment listings.

### [WatchDog](https://github.com/Pythoneers-Dev-0-2025-2026/WatchDog)
**Python · Kotlin · WebSockets · OpenCV**

Cross-device workstation security system built at the **Dev0 Hackathon**, where it placed **2nd Overall**. Uses persistent desktop-mobile communication, computer vision, remote locking, and multi-stage threat confirmation.
